      🔄 FPL Mini-League Sync

      Pulls standings, gameweek points, transfer costs, and chip usage from the official FPL site for this league, and writes them straight into the Grading and Performance pages.

      ⚠️ The official FPL API doesn't allow browser pages to call it directly (a security rule on their end, not a setting here), so this goes through a public CORS proxy to reach it. That proxy is a third-party service outside anyone's control — if a sync fails, it's almost always the proxy being briefly down, not a fault in this file. The proxy URL below can be swapped for another if needed. Also: "auto-sync" only runs while this browser tab stays open, the same as any webpage — it can't run in the background once the tab or browser is closed.

      ⚡ Automatic Sync via GitHub Actions

      Alternative to the proxy above: a GitHub Action in this site's own repo fetches FPL data server-side (no browser CORS issue at all — Actions runners aren't browsers) on a schedule, and writes a snapshot file the app can load directly. Set this up once; after that "Run GitHub Action Now" or the schedule keeps it fresh with no proxy dependency.
